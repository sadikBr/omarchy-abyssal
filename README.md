# Abyssal

A dark [Omarchy](https://omarchy.org) theme from the deep ocean: abyssal navy
and teal, lit by bioluminescent cyan, with coral, sea-glass and jellyfish
violet accents.

## Install

```bash
omarchy theme install https://github.com/sadikBr/omarchy-abyssal
omarchy theme set abyssal
```

Omarchy generates the terminal, Hyprland, Neovim, btop, VS Code and other app
configs from `colors.toml`.

## Backgrounds

There are eight ocean photographs, each cropped to 21:9 and stored at exactly
3440×1440. They were downscaled from 4K–8K originals and never upscaled, so
they are pixel-sharp on an ultrawide monitor. Cycle them with the background
switcher (Super + Ctrl + Space).
